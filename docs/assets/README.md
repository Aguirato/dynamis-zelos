# Visual assets

All published illustrations use English labels and the DYNAMIS ZELOS black,
yellow and white identity from the supplied concept. The SVGs are editable
vector source files created for this repository.

- `header.svg`: concept banner; the device is an illustration, not a product photograph.
- `architecture.svg`: implemented signal path and interpretation limits.
- `wiring.svg`: logical signal map for the documented reference boards;
  not a PCB layout or a substitute for manufacturer assembly instructions.
- `mark.svg`: simplified vector brand mark.
- `dashboard.jpg`: actual browser screenshot with synthetic demo data.

The source concept posters are not republished as technical evidence: their
Portuguese labels and unverified product claims have been replaced by the
English guides and diagrams. See the concept comparison table in the root
README for the differences between the pictured product and this prototype.

These first-party visuals are covered by the repository's non-commercial
license. Referenced manufacturer product names remain their owners' marks.
